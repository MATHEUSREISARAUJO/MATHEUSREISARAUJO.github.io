# Memórias de Cozinha

Amostra estática de um site autoral de confeitaria. Abra `index.html` no navegador para visualizar.

## Arquivos do site

| Arquivo | Conteúdo |
| --- | --- |
| `index.html` | Abertura e apresentação do confeiteiro |
| `album.html` | Memórias e histórias |
| `estilo.css` | Cores, tipografia e layout |
| `cena.js` | Animação do açúcar vinculada à rolagem |
| `abertura.png` e `doces.png` | Imagens geradas para a amostra |

Registre suas ideias em [Minhas mudanças](MINHAS-MUDANCAS.md). As anotações servem como pauta de edição. Para aplicar uma mudança, edite os arquivos correspondentes acima.

## GitHub e hospedagem

Os seis arquivos do site podem ir juntos na raiz de um repositório ou na pasta escolhida para publicação. O projeto usa HTML, CSS e JavaScript, com caminhos relativos e sem etapa de compilação.

Para a fase editorial, o [GitHub Pages](https://docs.github.com/en/pages/quickstart) oferece hospedagem gratuita a partir de um repositório público no plano GitHub Free. A fonte de publicação pode ser configurada em **Settings → Pages**. Antes de acrescentar vendas, confira os [limites de uso do GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/github-pages-limits).

A [Oracle Cloud Always Free](https://docs.oracle.com/en-us/iaas/Content/FreeTier/freetier_topic-Always_Free_Resources.htm) oferece instâncias gratuitas sujeitas à capacidade da região. Hospedar em uma delas exige configurar e manter o servidor e o HTTPS.
